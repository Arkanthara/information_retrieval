Modèle Probabiliste (BIR)

Des documents bruts à la réponse à une requête

Binary Independence Retrieval Probability Ranking Principle Odds Ratio RSJ Model BM25 / OKAPI TF·IDF
Section 1

Résumé exécutif (30 secondes)

🎯 Définition

Le modèle probabiliste BIR (Binary Independence Retrieval) est un cadre de récupération d'information qui estime la probabilité de pertinence \(P(R \mid d_j, q)\) de chaque document \(d_j\) par rapport à une requête \(q\). Il est fondé sur deux hypothèses clés : les occurrences de termes sont binaires (présent/absent) et indépendantes entre elles au sein d'un document.

Idée principale : Le pipeline part de documents bruts, les transforme en représentations TF·IDF, puis utilise le théorème de Bayes et le rapport de cotes pour estimer la pertinence, aboutissant à une liste ordonnée par \(\text{RSV}(d_j, q)\) décroissant.

Importance : Le BIR est la fondation théorique de BM25 (OKAPI), encore aujourd'hui le modèle de référence en RI probabiliste, implanté dans Elasticsearch, Lucene, Solr et les systèmes RAG modernes.

Section 2

Réponse modèle d'oral (2–5 minutes)

💬 Réponse prononçable

Le modèle probabiliste BIR décrit un pipeline allant des documents bruts jusqu'à la réponse ordonnée à une requête. Permettez-moi d'en décrire les étapes.

Étape 1 — De l'objet textuel à la représentation vectorielle

On part d'une collection de \(N\) documents textuels. Chaque document est analysé pour en extraire les termes constitutifs d'un vocabulaire de taille \(M\). L'embedding TF·IDF représente chaque document \(d_j\) comme un vecteur de \(\mathbb{R}^M\), où chaque coordonnée \(w_{ij} = \text{tf}_{ij} \cdot \text{idf}_i\) pondère la fréquence locale du terme par sa rareté globale dans la collection.

Étape 2 — Le principe de classement probabiliste

Le cadre théorique repose sur le Probability Ranking Principle de Robertson (1977) : un système optimal présente les documents dans l'ordre décroissant de leur probabilité de pertinence \(P(R = \text{vrai} \mid d_j, q)\). La tâche est donc d'estimer cette probabilité.

Étape 3 — La décision bayésienne et le rapport de cotes

Pour éviter de fixer un seuil absolu, on utilise le rapport de cotes bayésien : \(O(R \mid d_j, q) = P(R \mid d_j, q) / P(\bar{R} \mid d_j, q)\). Par le théorème de Bayes, ce rapport est proportionnel à \(P(d_j \mid R, q) / P(d_j \mid \bar{R}, q)\), c'est-à-dire le rapport de vraisemblance du document entre la classe pertinente et non-pertinente.

Étape 4 — Les hypothèses Binary Independence

Le modèle BIR pose deux hypothèses simplificatrices : l'occurrence de chaque terme est binaire — présent ou absent — et les termes sont indépendants au sein du document. Ces hypothèses permettent de décomposer \(P(d_j \mid R, q)\) comme un produit sur les termes présents dans \(d_j\).

Étape 5 — La formule RSV

Après simplification algébrique, on obtient : \(\text{RSV}(d_j, q) \propto \sum_{i \in \mathcal{I}_j \cap \mathcal{I}_q} c_i\) où \(c_i\) est un log-odds pondérant la contribution de chaque terme commun entre le document et la requête.

Étape 6 — L'estimation itérative et BM25

Les probabilités \(P(t_i \mid R, q)\) et \(P(t_i \mid \bar{R}, q)\) sont estimées par comptage sur un pseudo-feedback. À l'initialisation, cette estimation se réduit à l'IDF classique. Le modèle BIR a évolué vers le modèle RSJ de Robertson-Sparck-Jones, puis vers la formule BM25 qui intègre la fréquence des termes et la longueur du document, constituant encore aujourd'hui le meilleur baseline probabiliste.

Section 3

Explication approfondie

3.1 — Notation et setup formel

Toute la chaîne de traitement repose sur la notation suivante :

Collection

\(N\) : nombre de documents dans la collection
\(M\) : taille du vocabulaire
\(d_j\) : représentation du \(j\)-ième document
\(\mathcal{I}_j \subseteq [\![M]\!]\) : indices des termes présents dans \(d_j\)

Requête et RSV

\(q\) : représentation de la requête
\(\mathcal{I}_q\) : indices des termes de la requête
\(\text{RSV}(d_j, q) \in \mathbb{R}\) : valeur de statut de récupération
→ ordonnancement par RSV décroissant

3.2 — Étape 1 : Des documents bruts à la représentation TF·IDF

Les documents arrivent sous forme de textes bruts (séquences de mots). Le modèle Bag of Words (BoW) ignore l'ordre et la structure, ne retenant que les fréquences des termes. Le schéma de pondération TF·IDF (Term Frequency — Inverse Document Frequency) constitue la base de représentation :

TF normalisée
$$\text{tf}_{ij} = \frac{f_{ij}}{\max_k f_{kj}}$$

où \(f_{ij}\) est le nombre brut d'occurrences du terme \(i\) dans le document \(j\). La normalisation par le terme le plus fréquent garantit \(\max_i \text{tf}_{ij} = 1\).

IDF
$$\text{idf}_i = \log \frac{N}{n_i}$$

où \(n_i\) est le nombre de documents contenant le terme \(i\). Un terme présent dans tous les documents a \(\text{idf}_i \approx 0\) (non discriminant).

Poids TF·IDF
$$w_{ij} = \text{tf}_{ij} \cdot \text{idf}_i, \qquad W = [w_{ij}]_{M \times N} \in \mathbb{R}^{M \times N}$$

La matrice \(W\) est la représentation centrale de toute la collection. La colonne \(W_{\cdot j} = d_j\) est l'embedding du document \(j\).

🔗 Connexion BIR ↔ TF·IDF

Le modèle BIR part de l'embedding TF·IDF mais va plus loin : il remplace les poids scalaires déterministes \(w_{ij}\) par des probabilités de pertinence \(P(t_i \mid R, q)\), fondées sur l'hypothèse que les termes discriminants pour une requête sont aussi ceux qui sont plus fréquents dans les documents pertinents que dans les non-pertinents.

3.3 — Étape 2 : Le Probability Ranking Principle (PRP)

📖 Robertson, Journal of Documentation, 1977

Si la réponse d'un système de référence à chaque requête est un classement des documents dans l'ordre décroissant de probabilité d'utilité pour l'utilisateur, estimée aussi précisément que possible sur les données disponibles, alors l'efficacité globale du système sera la meilleure obtainable sur ces données.

Formalisation : On introduit une variable aléatoire de Bernoulli \(R \in \{0, 1\}\) indiquant la pertinence. La tâche est d'estimer et de maximiser \(P(R = 1 \mid d_j, q)\), ce qui revient à trier les documents par ordre décroissant de cette probabilité.

3.4 — Étape 3 : Décision bayésienne et rapport de cotes

Plutôt que de fixer un seuil absolu \(P(R \mid d_j, q) > \tau\), on travaille avec le rapport de cotes bayésien (Odds Ratio) :

Odds Ratio
$$O(R \mid d_j, q) = \frac{P(R = 1 \mid d_j, q)}{P(R = 0 \mid d_j, q)}$$

En appliquant le théorème de Bayes à chaque facteur :

Théorème de Bayes
$$O(R \mid d_j, q) = \frac{P(d_j \mid R, q) \cdot P(R \mid q)}{P(d_j \mid \bar{R}, q) \cdot P(\bar{R} \mid q)}$$

Comme \(P(R \mid q)\) est constant pour tous les documents d'une même requête, il peut être ignoré pour le classement :

Simplification
$$O(R \mid d_j, q) \;\propto\; \frac{P(d_j \mid R, q)}{P(d_j \mid \bar{R}, q)}$$

Intuition : on cherche à quantifier à quel point le document \(d_j\) est plus probable parmi les documents pertinents que parmi les non-pertinents.

3.5 — Étape 3b : Régression logistique pour la RI

Une première instanciation du cadre bayésien consiste à supposer que le log-rapport de cotes est une fonction log-linéaire des features du document :

$$\log O(R \mid d_j, q) = \phi_\theta(d_j, q) = w^T d_j + w_0$$

On obtient alors le modèle de régression logistique :

$$P(R \mid d_j, q) = \sigma_\theta(d_j) = \frac{1}{1 + e^{-(w^T d_j + w_0)}}$$

Les paramètres \(\theta = [w, w_0]\) sont appris par descente de gradient sur des paires de pertinence annotées \((D, Q)\). Les features typiques incluent les poids TF·IDF et la longueur du document.

✓ Avantages

  • Modèle de pertinence absolu
  • Apprentissage en ligne via feedback
  • Tout embedding peut être utilisé

✗ Limites

  • Choix des features critique
  • Lent si réentraînement à chaque requête
  • Nécessite des données annotées

3.6 — Étape 4 : Le modèle BIR — hypothèses et dérivation

⚙️ Les deux hypothèses fondatrices

Hypothèse 1 — Binaire (Binary) : L'occurrence de chaque terme \(t_i\) dans un document est binaire : le terme est présent (\(w_{ij} = 1\)) ou absent (\(w_{ij} = 0\)). On ignore la fréquence des termes dans les documents.

Hypothèse 2 — Indépendante (Independence) : Les occurrences des termes sont conditionnellement indépendantes étant donné la classe de pertinence. C'est la même hypothèse que dans un classifieur naïf bayésien (Naïve Bayes).

Décomposition : Sous ces hypothèses, la vraisemblance du document se factorise :

Factorisation
$$P(d_j \mid R, q) = \prod_{i \in \mathcal{I}_j} P(t_i \mid R, q) \;\cdot\; \prod_{i \notin \mathcal{I}_j} \bigl(1 - P(t_i \mid R, q)\bigr)$$

En combinant numérateur et dénominateur dans le rapport de cotes :

$$O(R \mid d_j, q) \;\propto\; \prod_{i \in \mathcal{I}_j} \frac{P(t_i \mid R, q)}{P(t_i \mid \bar{R}, q)} \cdot \prod_{i \notin \mathcal{I}_j} \frac{1 - P(t_i \mid R, q)}{1 - P(t_i \mid \bar{R}, q)}$$

Par une simplification algébrique (on peut réécrire le second produit des termes absents comme un produit sur les termes présents grâce à la complémentarité), on passe en logarithme :

Log-Odds RSV
$$\log O(R \mid d_j, q) \;\propto\; \sum_{i \in \mathcal{I}_j} \left[ \log \frac{P(t_i \mid R, q)}{1 - P(t_i \mid R, q)} + \log \frac{1 - P(t_i \mid \bar{R}, q)}{P(t_i \mid \bar{R}, q)} \right]$$

Enfin, on note que pour les termes absents de la requête (\(i \notin \mathcal{I}_q\)), on a \(P(t_i \mid R, q) = P(t_i \mid \bar{R}, q)\), donc leur contribution s'annule. La formule RSV finale est :

RSV final BIR
$$\boxed{\text{RSV}(d_j, q) \;\propto\; \sum_{i \in [\![M]\!]} w_{ij}^{\text{bin}}\, w_{iq}^{\text{bin}} \left[ \log \frac{P(t_i \mid R, q)}{1 - P(t_i \mid R, q)} + \log \frac{1 - P(t_i \mid \bar{R}, q)}{P(t_i \mid \bar{R}, q)} \right]}$$

où \(w_{ij}^{\text{bin}}\) et \(w_{iq}^{\text{bin}}\) sont les indicateurs binaires de présence du terme \(i\) dans \(d_j\) et \(q\) respectivement. La double présence dans le document ET dans la requête est nécessaire pour contribuer au RSV.

3.7 — Étape 5 : Estimation itérative des probabilités

Les probabilités \(P(t_i \mid R, q)\) et \(P(t_i \mid \bar{R}, q)\) ne sont pas connues a priori. On les estime par comptage sur un ensemble de pseudo-feedback noté \(S\) des \(r\) premiers documents récupérés :

  • 1
    Initialisation — sans feedback (query time) \(P(t_i \mid R, q) = \rho\) (constante uniforme), \(\quad P(t_i \mid \bar{R}, q) = n_i / N\)
    → On note alors : \(\log \frac{1 - P(t_i \mid \bar{R}, q)}{P(t_i \mid \bar{R}, q)} = \log \frac{N - n_i}{n_i} \approx \log \frac{N}{n_i} = \text{idf}_i\)
    🔗 À l'initialisation, le BIR se réduit à l'IDF !
  • 2
    Définition des compteurs \(r_i\) = nombre de documents dans \(S\) contenant le terme \(i\)
    \(n_i\) = nombre total de documents dans la collection contenant le terme \(i\)
  • 3
    Estimation avec pseudo-feedback $$P(t_i \mid R, q) = \frac{r_i}{r}, \qquad P(t_i \mid \bar{R}, q) = \frac{n_i - r_i}{N - r}$$
  • 4
    Itération jusqu'à convergence Recalculer le RSV, récupérer les \(r\) premiers documents, mettre à jour les estimations. Répéter.

3.8 — Étape 6 : Le modèle RSJ et la formule BM25

Le BIR de base a été amélioré par Robertson & Sparck-Jones (RSJ) avec un lissage de type "+0.5" pour éviter les probabilités nulles :

Poids RSJ
$$w_i^{\text{RSJ}} = \log \frac{(r_i + 0.5)(N - R - n_i + r_i + 0.5)}{(n_i - r_i + 0.5)(R - r_i + 0.5)}$$

Ce lissage de Laplace évite les probabilités nulles et offre une meilleure régularisation, surtout pour des collections de petite taille ou des termes rares.

La formule BM25 (Best Match 25, aussi appelée OKAPI BM25) étend le modèle RSJ en réintroduisant la fréquence des termes et la normalisation par la longueur du document :

BM25
$$w_i^{\text{BM25}}(tf) = \frac{tf}{k_1\!\left((1-b) + b\,\frac{dl}{avdl}\right) + tf} \cdot w_i^{\text{RSJ}}$$

\(tf\) : fréquence du terme dans le document  ·  \(dl\) : longueur du document  ·  \(avdl\) : longueur moyenne des documents
\(k_1 \approx 1.2\) : contrôle la saturation de la TF  ·  \(b \approx 0.75\) : contrôle la normalisation par la longueur

La formule BM25 complète avec gestion de la fréquence dans la requête (\(qtf\)) :

BM25 complet
$$\text{RSV}^{\text{BM25}}(d_j, q) = \sum_{T \in Q} w^{(1)}\! \frac{(k_1+1)\,tf}{K + tf} \cdot \frac{(k_3+1)\,qtf}{k_3 + qtf}$$

\(K = k_1\!\left((1-b) + b\,\frac{dl}{avdl}\right)\), \(\; qtf\) = fréquence du terme dans la requête, \(k_3 \approx 7\)

Section 5

Formules importantes

1. TF·IDF — Base de représentation

$$\text{tf}_{ij} = \frac{f_{ij}}{\max_k f_{kj}}, \qquad \text{idf}_i = \log\frac{N}{n_i}, \qquad w_{ij} = \text{tf}_{ij} \cdot \text{idf}_i$$
Variables : \(f_{ij}\) = occurrences brutes, \(n_i\) = documents contenant \(t_i\), \(N\) = total documents.
Intuition : tf mesure l'importance locale, idf mesure la rareté globale (pouvoir discriminant). Un terme fréquent dans un document mais rare dans la collection obtient un poids élevé.

2. Rapport de cotes bayésien (Odds Ratio)

$$O(R \mid d_j, q) = \frac{P(R \mid d_j, q)}{P(\bar{R} \mid d_j, q)} \;\propto\; \frac{P(d_j \mid R, q)}{P(d_j \mid \bar{R}, q)}$$
Intuition : On n'a pas besoin de normaliser : trier par \(O(R \mid d_j, q)\) est équivalent à trier par \(P(R \mid d_j, q)\). La proportionnalité élimine le terme constant \(P(R \mid q) / P(\bar{R} \mid q)\).
Avantage : Pas de seuil \(\tau\) à fixer — le classement est suffisant pour la RI.

3. BIR — Factorisation sous indépendance

$$P(d_j \mid R, q) = \prod_{i \in \mathcal{I}_j} P(t_i \mid R, q) \cdot \prod_{i \notin \mathcal{I}_j} (1 - P(t_i \mid R, q))$$
Hypothèse : termes binaires + indépendants (Naïve Bayes sur les termes).
Interprétation : La vraisemblance du document est le produit des vraisemblances de présence/absence de chaque terme.

4. RSV(BIR) — Formule finale

$$\text{RSV}(d_j, q) \propto \sum_{i \in \mathcal{I}_j \cap \mathcal{I}_q} \left[ \log \frac{P(t_i \mid R, q)}{1 - P(t_i \mid R, q)} + \log \frac{1 - P(t_i \mid \bar{R}, q)}{P(t_i \mid \bar{R}, q)} \right]$$
Interprétation : Seuls les termes communs au document et à la requête contribuent. Chaque terme contribue par son log-ratio de pertinence côté relevants moins le log-ratio côté non-relevants.

5. Estimation initiale → connexion IDF

$$P(t_i \mid R, q) = \rho \text{ (cste)}, \quad P(t_i \mid \bar{R}, q) = \frac{n_i}{N}$$ $$\Rightarrow\; \log \frac{1 - P(t_i \mid \bar{R}, q)}{P(t_i \mid \bar{R}, q)} = \log\frac{N - n_i}{n_i} \approx \log\frac{N}{n_i} = \text{idf}_i$$
Connexion fondamentale : À l'initialisation (sans feedback), le BIR se réduit à un score IDF — le modèle probabiliste généralise TF·IDF.

6. Poids RSJ (Robertson-Sparck-Jones)

$$w_i^{\text{RSJ}} = \log \frac{(r_i + 0.5)(N - R - n_i + r_i + 0.5)}{(n_i - r_i + 0.5)(R - r_i + 0.5)}$$
\(r_i\) = docs pertinents contenant \(t_i\), \(R\) = total docs pertinents, \(n_i\) = docs contenant \(t_i\), \(N\) = total docs.
Lissage : Le "+0.5" de Laplace évite les probabilités nulles pour les termes rares.

7. BM25 — Best Match 25 (OKAPI)

$$\text{RSV}^{\text{BM25}} = \sum_{T \in Q} w^{\text{RSJ}}\!\cdot\frac{(k_1+1)\,tf}{k_1\!\left((1-b)+b\,\frac{dl}{avdl}\right)+tf}\cdot\frac{(k_3+1)\,qtf}{k_3+qtf}$$
Paramètres par défaut : \(k_1 = 1.2\), \(b = 0.75\), \(k_3 = 7\).
Saturation : Quand \(tf \to \infty\), la fraction TF sature à \((k_1+1)/k_1 \approx 1.83\) — on évite qu'un terme très fréquent domine infiniment.
Normalisation longueur : \(b=1\) = normalisation totale, \(b=0\) = pas de normalisation.

📊 Position de BM25 dans l'écosystème

BM25 est encore le baseline de référence en IR probabiliste. En pratique, les systèmes modernes utilisent souvent une combinaison BM25 + Dense Retrieval (Hybrid Search), où BM25 gère la précision lexicale et le modèle dense gère la sémantique. Des travaux récents (Formal et al., 2021) montrent que BM25 reste compétitif même face aux modèles neuronaux sur de nombreux benchmarks BEIR.

Perspective historique

1960s
Modèle Booléen — Premiers systèmes IR
Systèmes basés sur la logique booléenne (AND/OR/NOT). Documents et requêtes comme ensembles de termes. Pas de ranking.
1971–1972
TF·IDF — Karen Spärck Jones
Introduction du concept d'IDF (Inverse Document Frequency). Formulation de la pondération TF·IDF comme score de pertinence continu.
1977
Probability Ranking Principle — S.E. Robertson
Fondement théorique du classement probabiliste. Formalisation de l'objectif : maximiser \(P(R \mid d_j, q)\).
1980s
BIR — Binary Independence Retrieval
Modèle de Robertson & Sparck-Jones : hypothèses binaires et indépendantes. Lien formel entre la probabilité de pertinence et l'IDF à l'initialisation.
1994–1999
BM25 / OKAPI — Robertson et al.
Formule BM25 présentée au TREC-3 (1994). Intègre TF saturée et normalisation par longueur. Devient le standard probabiliste. Paramètres \(k_1 \approx 1.2\), \(b \approx 0.75\).
2003–2013
Language Models pour IR — LDA, Word2Vec
Modèles de langue pour la RI (Ponte & Croft, 1998). Topic models (LDA, 2003). Premiers embeddings denses (Word2Vec, 2013).
2019–2023
Neural / Dense Retrieval — BERT, DPR, ColBERT
Représentations denses avec encodeurs Transformer (DPR, 2020 ; ColBERT, 2020 ; E5, BGE, 2022–2023). BM25 reste le baseline lexical dans les systèmes hybrides.
2023–présent
Hybrid Retrieval + RAG
RAG (Retrieval-Augmented Generation) combine BM25 (lexical) et dense retrieval dans un pipeline hybride. BM25 reste incontournable pour la précision lexicale exacte.
Section 9

Liens avec les systèmes modernes

🔍 Elasticsearch / Lucene / Solr

BM25 est le scoring par défaut depuis Elasticsearch 5.x (2016). Paramètres \(k_1\) et \(b\) configurables via les field mappings. Apache Lucene implémente la classe BM25Similarity.

🤖 RAG (Retrieval-Augmented Generation)

Dans les pipelines RAG, BM25 sert souvent de sparse retriever pour la phase de première passe (first-stage retrieval) avant le re-ranking neural. Framework : LangChain, LlamaIndex, Haystack.

🔀 Hybrid Retrieval

Combinaison de BM25 (précision lexicale) et de dense embeddings (BERT, E5…) via reciprocal rank fusion (RRF) ou un modèle de fusion appris. Meilleur des deux mondes : rappel sémantique + précision exacte.

⚡ SPLADE / ColBERT (sparse dense)

Les modèles comme SPLADE (2021) apprennent des représentations sparse dans l'espace lexical mais avec pondérations neuronales — une généralisation de BM25 avec des termes expansés par des LLMs.

🏆 Benchmarks BEIR

Sur le benchmark BEIR (Thakur et al., 2021), BM25 est competitive face aux encodeurs denses sur plusieurs datasets, notamment pour les requêtes avec termes spécifiques. Il reste la référence sur des domaines spécialisés (médical, légal).

⚠️ Limites du BM25 en 2025

Vocabulaire fermé (OOV), sensible à l'orthographe, incapable de gérer synonymes/paraphrases. Pas d'inférence cross-linguale. Pour ces raisons, les dense retrievers le complètent plutôt qu'ils ne le remplacent.

Section 10

Questions d'examen possibles

Niveau facile

Qu'est-ce que le Retrieval Status Value (RSV) ?Facile

Le RSV est une fonction \(\text{RSV}(d_j, q) \in \mathbb{R}\) qui mesure la pertinence estimée du document \(d_j\) par rapport à la requête \(q\). Dans le modèle BIR, il est défini comme le log-rapport de cotes \(\log O(R \mid d_j, q)\). L'ordonnancement des documents par RSV décroissant constitue la réponse à la requête.

Pourquoi le modèle BIR s'appelle-t-il Binary Independence ?Facile

Binary : l'occurrence de chaque terme dans un document est modélisée comme une variable binaire (présent/absent) — on ignore la fréquence réelle du terme dans le document.
Independence : les occurrences des termes sont supposées conditionnellement indépendantes étant donné la classe de pertinence. Cette hypothèse permet d'écrire \(P(d_j \mid R, q) = \prod_i P(t_i \mid R, q)^{w_{ij}} \cdot (1 - P(t_i \mid R, q))^{1-w_{ij}}\), un modèle de Naïve Bayes sur les termes.

Quelle est la connexion entre le BIR à l'initialisation et l'IDF ?Facile

À l'initialisation (sans feedback), on fixe \(P(t_i \mid R, q) = \rho\) (constante) et \(P(t_i \mid \bar{R}, q) = n_i/N\). Le terme de non-pertinence du log-odds devient alors : $$\log \frac{1 - n_i/N}{n_i/N} = \log \frac{N - n_i}{n_i} \approx \log \frac{N}{n_i} = \text{idf}_i$$ Ainsi, à l'initialisation, le BIR se réduit essentiellement à un classement par IDF. Cela montre que TF·IDF est un cas particulier du modèle probabiliste.

Niveau intermédiaire

Expliquez la décision bayésienne et le rôle du rapport de cotes dans le BIR.Intermédiaire

Plutôt que d'estimer directement \(P(R \mid d_j, q)\), on utilise le rapport de cotes (odds ratio) :
$$O(R \mid d_j, q) = \frac{P(R \mid d_j, q)}{P(\bar{R} \mid d_j, q)}$$ Par le théorème de Bayes :
$$O(R \mid d_j, q) = \frac{P(d_j \mid R, q) \cdot P(R \mid q)}{P(d_j \mid \bar{R}, q) \cdot P(\bar{R} \mid q)} \propto \frac{P(d_j \mid R, q)}{P(d_j \mid \bar{R}, q)}$$ Le terme \(P(R \mid q) / P(\bar{R} \mid q)\) est constant pour tous les documents d'une même requête, donc il n'affecte pas le classement et peut être ignoré. L'avantage est d'éviter de fixer un seuil absolu \(\tau\) pour décider si un document est pertinent — le classement par rapport de cotes décroissant suffit.

Décrivez la stratégie d'estimation itérative du BIR (pseudo-relevance feedback).Intermédiaire

1. Initialisation : On suppose \(P(t_i \mid R, q) = \rho\) (uniforme) et \(P(t_i \mid \bar{R}, q) = n_i/N\). Le RSV initial ≈ IDF.
2. Première récupération : On récupère les \(r\) premiers documents selon ce RSV initial.
3. Pseudo-feedback : On traite ces \(r\) documents comme pertinents (pseudo-relevance feedback). Pour chaque terme \(i\), on compte \(r_i\) (occurrences parmi les top-r) et on met à jour : \(P(t_i \mid R, q) = r_i/r\), \(P(t_i \mid \bar{R}, q) = (n_i - r_i)/(N - r)\).
4. Itération : On recalcule le RSV avec les nouvelles probabilités et on répète jusqu'à convergence.

Comment BM25 améliore-t-il le BIR de base ? Quel est le rôle de k₁ et b ?Intermédiaire

BM25 enrichit le BIR (qui est purement binaire) en réintroduisant :
1. La fréquence des termes (TF) : via une saturation contrôlée \(\frac{(k_1+1) \cdot tf}{K + tf}\). Quand \(tf \to \infty\), la fraction sature à \((k_1+1)/k_1\), évitant qu'un terme très répété domine infiniment.
2. La normalisation par la longueur : \(K = k_1((1-b) + b \cdot dl/avdl)\). Cela pénalise les longs documents qui accumulent naturellement plus de fréquences.
k₁ ≈ 1.2 : contrôle la saturation de la TF (faible k₁ = saturation rapide = proche du binaire).
b ≈ 0.75 : contrôle la force de la normalisation par longueur (b=0 = pas de normalisation, b=1 = normalisation complète).

Niveau difficile

Dérivez formellement la formule RSV(BIR) à partir du rapport de cotes, en détaillant les simplifications algébriques.Difficile

Sous les hypothèses binaires et indépendantes : $$O(R \mid d_j, q) \propto \frac{\prod_{i \in \mathcal{I}_j} P(t_i \mid R, q)}{\prod_{i \in \mathcal{I}_j} P(t_i \mid \bar{R}, q)} \cdot \frac{\prod_{i \notin \mathcal{I}_j} (1 - P(t_i \mid R, q))}{\prod_{i \notin \mathcal{I}_j} (1 - P(t_i \mid \bar{R}, q))}$$ On réécrit le second produit en l'étendant à tous les termes et en compensant avec un produit sur les termes présents : $$= \prod_{i \in \mathcal{I}_j} \frac{P(t_i \mid R, q)}{P(t_i \mid \bar{R}, q)} \cdot \frac{1-P(t_i \mid \bar{R}, q)}{1-P(t_i \mid R, q)} \cdot \underbrace{\prod_i \frac{1-P(t_i \mid R, q)}{1-P(t_i \mid \bar{R}, q)}}_{\text{const./document}}$$ En passant au log et en ignorant la constante : $$\text{RSV} \propto \sum_{i \in \mathcal{I}_j} \left[\log \frac{P(t_i \mid R)}{1-P(t_i \mid R)} + \log \frac{1-P(t_i \mid \bar{R})}{P(t_i \mid \bar{R})}\right]$$ Pour les termes absents de la requête, \(P(t_i \mid R) = P(t_i \mid \bar{R})\) — leur contribution est nulle — d'où l'intersection \(\mathcal{I}_j \cap \mathcal{I}_q\).

En quoi le BIR est-il une généralisation du classifieur Naïve Bayes ? Quelles sont les implications théoriques ?Difficile

Le BIR est exactement un classifieur Naïve Bayes (NB) binaire appliqué aux termes. Dans un NB, pour des features binaires \(x_i\), on a \(P(x \mid C) = \prod_i P(x_i \mid C)^{x_i}(1-P(x_i \mid C))^{1-x_i}\), avec indépendance conditionnelle. Le BIR utilise précisément cette décomposition avec \(C \in \{R, \bar{R}\}\) (pertinent/non-pertinent) et \(x_i = w_{ij}^{\text{bin}}\).
Implications : (1) L'hypothèse d'indépendance est forte — en pratique, les termes sont corrélés (co-occurrences). Malgré cette violation, NB et BIR sont souvent robustes empiriquement. (2) La connexion avec NB suggère des extensions possibles : NB multivariable, distributions de Dirichlet pour le lissage, etc. (3) Le BIR peut être vu comme un modèle discriminatif si on paramétrise directement les log-odds par régression logistique.

Section 11

Pièges classiques et erreurs fréquentes

⚠️ Confondre RSV et probabilité

Le RSV dans BIR est un log-rapport de cotes, pas directement une probabilité \(P(R \mid d_j, q)\). Pour obtenir la probabilité, il faut appliquer la sigmoïde.

⚠️ Croire que BIR ignore la fréquence

Le BIR de base est binaire (presence/absence), mais BM25 réintègre la TF avec saturation. Ne pas confondre BIR et BM25 sur ce point crucial.

⚠️ Oublier que PRP suppose un ranking parfait

Le PRP prouve l'optimalité du ranking par probabilité de pertinence si les probabilités sont exactes. En pratique, elles sont approximées et le ranking reste sous-optimal.

⚠️ Initialisation sans feedback ≠ BM25

À l'initialisation, le BIR ≈ IDF, pas TF·IDF complet. BM25 inclut la TF saturée et la normalisation par longueur — c'est une évolution de RSJ, pas directement du BIR de base.

⚠️ Indépendance = hypothèse violée

Les termes ne sont pas indépendants en pratique (synonymes, co-occurrences). Le modèle fonctionne bien empiriquement malgré cette violation — ne pas l'ignorer à l'oral !

⚠️ b=0 dans BM25 = pas de normalisation

Avec \(b=0\), BM25 ne normalise pas par la longueur du document. Avec \(b=1\), la normalisation est totale. La valeur empirique \(b \approx 0.75\) est un compromis standard.

⚠️ Pseudo-feedback peut dégrader les résultats

Si les top-r documents initiaux sont tous non-pertinents (erreur de la première passe), le pseudo-feedback amplifie l'erreur. Cette dérive (query drift) est un problème bien connu.

⚠️ P(R|q) ≠ constant dans tous les cas

La proportionnalité \(O(R \mid d_j, q) \propto P(d_j \mid R)/P(d_j \mid \bar{R})\) nécessite que \(P(R \mid q)\) soit constant pour tous les documents d'une même requête — ce qui est vrai mais doit être expliqué explicitement.

🔢 Formules essentielles

TF : tf_ij = f_ij / max_k(f_kj)  ·  IDF : idf_i = log(N/n_i)  ·  w_ij = tf × idf
Odds Ratio : O(R|d_j,q) ∝ P(d_j|R,q) / P(d_j|R̄,q)
RSV(BIR) ∝ Σ_{i∈I_j∩I_q} [ log P(tᵢ|R)/(1-P(tᵢ|R)) + log (1-P(tᵢ|R̄))/P(tᵢ|R̄) ]
Init sans feedback : P(tᵢ|R̄) = nᵢ/N → log-odds ≈ IDF
RSJ : w_i = log[(r_i+0.5)(N-R-n_i+r_i+0.5) / ((n_i-r_i+0.5)(R-r_i+0.5))]
BM25 : w_i^RSJ · tf/(k₁((1-b)+b·dl/avdl)+tf) · (k₃+1)qtf/(k₃+qtf)  ·  k₁≈1.2, b≈0.75

📊 Pipeline BIR en 6 étapes

  • 1. Textes bruts → Vocabulaire M termes → Embedding TF·IDF → Matrice W
  • 2. PRP : objectif = classer par P(R=1 | d_j, q) décroissant
  • 3. Bayes + Odds Ratio : O(R|d_j,q) ∝ P(d_j|R,q) / P(d_j|R̄,q)
  • 4. BIR (binaire + indépendant) : RSV = Σ w_ij w_iq [log-odds termes]
  • 5. Estimation : init ≈ IDF, puis itérations avec r_i (pseudo-feedback)
  • 6. BM25 : RSJ + TF saturée + normalisation longueur → classement final

⚖️ Comparaison rapide

  • Boolean : RSV ∈ {0,1}, pas de ranking, SQL-like
  • VSM : cosinus TF·IDF, ranking continu, pas de base probabiliste
  • BIR : probabiliste, binaire, indépendant, lié à IDF au départ
  • BM25 : BIR + TF + longueur, paramètres k₁/b, référence industrielle

🎯 Points à mémoriser pour l'oral

  • BIR ≡ Naïve Bayes sur termes binaires, deux hypothèses (Binary, Independence)
  • Initialisation BIR sans feedback → RSV ≈ Σ IDF (connexion directe avec TF·IDF)
  • BM25 = standard industriel (Elasticsearch, Lucene) ; paramètres k₁ ≈ 1.2, b ≈ 0.75
  • PRP de Robertson (1977) : classer par probabilité de pertinence = optimal (si proba exactes)
  • En 2025 : BM25 + Dense Retrieval = Hybrid Search, pipeline RAG
